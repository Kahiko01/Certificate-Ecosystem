============================================
API ENDPOINTS
============================================
Login:    POST http://localhost:8001/auth/login
Register: POST http://localhost:8001/auth/register
Me:       GET  http://localhost:8001/auth/me
Roles:    GET  http://localhost:8001/auth/roles
Refresh:  POST http://localhost:8001/auth/refresh

============================================
TEST COMMANDS
============================================
# Login
curl -X POST http://localhost:8001/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"system_admin","password":"admin_hash"}'

# Get current user
curl -X GET http://localhost:8001/auth/me \
  -H "Authorization: Bearer YOUR_TOKEN_HERE"

# Get all roles
curl http://localhost:8001/auth/roles
