# 🏛️ Dean's Dashboard - User Guide

## Overview
The Dean's Dashboard provides a comprehensive overview of faculty, students, and departmental performance across the university.

## Features

### 1. 📤 Upload Data
- Upload Excel/CSV files with faculty and student data
- Supports .xlsx, .xls, .csv formats
- Auto-detects and maps columns

### 2. 📊 Statistics
- **Total Students**: All enrolled students
- **Departments**: Number of departments
- **Faculty**: Total faculty members
- **Average GPA**: Overall academic performance
- **Passing Rate**: Percentage of students passing
- **Graduating**: Students eligible for graduation

### 3. 📋 Faculty Management
- View all faculty members
- Department assignment
- Title and specialization tracking
- Student load monitoring

### 4. 📊 Performance Analytics
- Department performance comparison
- GPA distribution by department
- Pass rate analysis
- Visual charts and graphs

### 5. 📋 Student Performance
- Track student progress by department
- GPA monitoring
- Status tracking (Pass/Fail)
- Quick action buttons

## Excel File Format

### Faculty Data
| Column | Type | Description |
|--------|------|-------------|
| Faculty Name | Text | Full name |
| Department | Text | Department name |
| Title | Text | Academic title |
| Specialization | Text | Area of expertise |
| Students | Number | Students assigned |

### Student Data
| Column | Type | Description |
|--------|------|-------------|
| Student Number | Text | Unique identifier |
| First Name | Text | Student's first name |
| Last Name | Text | Student's last name |
| Department | Text | Department name |
| Programme | Text | Programme name |
| GPA | Number | Grade Point Average |

## Quick Actions

| Action | Description |
|--------|-------------|
| 👨‍🏫 Add Faculty | Add new faculty member |
| 📤 Upload Data | Upload Excel file |
| 📊 Export Report | Export data to Excel |
